# Main Hall A/V Setup (Full Detailed)

## Projector Station Setup
- Move table to angled position in front of organ
- Retrieve screen → place on table → extend to desired height
- Retrieve projector table → screw legs → place in front of screen
- Bring projector → remove from bag → place on table
- Plug projector power into multiplug → multiplug to extension → extension to wall
- Connect HDMI to converter box → converter to projector
- Ensure converter has HDMI + Ethernet
- Turn on projector → adjust keystone, height, focus
- Use cord hide for safety
- Set up iMac as screen monitor

- Run extension cord to center aisle

- Plug in Owl power + HDMI
- Mount Owl on tripod
- Cover cords
